# CricInsight — Deterministic Cricket Metric Definitions & Formulas

All cricket analytics in CricInsight are calculated programmatically in Python using Pandas and NumPy directly from imported Cricsheet match records. No statistical metrics are ever generated by language models.

---

## 1. Batting Metrics

### 1.1 Total Runs
- **Definition**: Total runs accumulated by the batter off the bat.
- **Formula**:
  $$\text{Total Runs} = \sum \text{batter\_runs}$$
- **Source Field**: `deliveries.batter_runs`
- **Exclusions**: Extras (`extra_runs`: wides, no-balls, byes, leg-byes, penalty runs) are credited to the team total, not the batter.

### 1.2 Balls Faced
- **Definition**: Deliveries faced by the batter that count towards their individual innings length.
- **Formula**:
  $$\text{Balls Faced} = \sum \mathbf{1}_{[\text{is\_ball\_faced} = \text{True}]}$$
- **Scoring Convention**:
  - **Wide deliveries**: `is_wide = True` $\implies$ `is_ball_faced = False` (does NOT count as a ball faced).
  - **No-ball deliveries**: `is_noball = True` $\implies$ `is_ball_faced = True` (counts as a ball faced).
  - **Legal deliveries**: `is_ball_faced = True`.

### 1.3 Batting Average
- **Definition**: Average runs scored per dismissal.
- **Formula**:
  $$\text{Batting Average} = \begin{cases} \frac{\text{Total Runs}}{\text{Dismissals}}, & \text{if } \text{Dismissals} > 0 \\ \text{None (Undefined / N/A)}, & \text{if } \text{Dismissals} = 0 \end{cases}$$
  Where:
  $$\text{Dismissals} = \text{Innings Count} - \text{Not Outs}$$
- **Critical Edge Case**: If a player has never been dismissed across the queried window, batting average is mathematically undefined. CricInsight returns `None` (`N/A` in UI), never fabricating an arbitrary number or dividing by zero.

### 1.4 Batting Strike Rate
- **Definition**: Rate of scoring expressed as runs scored per 100 balls faced.
- **Formula**:
  $$\text{Strike Rate} = \frac{\text{Total Runs}}{\text{Balls Faced}} \times 100$$
- **Precondition**: If $\text{Balls Faced} = 0$, Strike Rate is $0.0$.

### 1.5 Boundaries & Milestone Counts
- **Fours**: Deliveries where `batter_runs == 4`.
- **Sixes**: Deliveries where `batter_runs == 6`.
- **Centuries**: Innings where player's total runs $\ge 100$.
- **Half-Centuries (50s)**: Innings where $50 \le \text{player's total runs} < 100$.

## 2. Bowling Metrics

### 2.1 Bowler-Credited Wickets
- **Definition**: Wickets credited directly to the bowler's individual record under official cricket scoring rules.
- **Included Dismissals (`bowler_credited_wicket = True`)**:
  - `caught`, `bowled`, `lbw` (leg before wicket), `stumped`, `hit wicket`.
- **Excluded Dismissals (`bowler_credited_wicket = False`)**:
  - `run out` (team dismissal; credited to fielder)
  - `retired hurt` (not a dismissal under Laws of Cricket)
  - `obstructing the field`, `timed out`.

### 2.2 Legal Overs Bowled
- **Definition**: Total legal overs bowled, accounting for fractional overs.
- **Formula**:
  $$\text{Legal Balls} = \sum \mathbf{1}_{[\text{is\_legal\_ball} = \text{True}]}$$
  $$\text{Overs} = \lfloor \frac{\text{Legal Balls}}{6} \rfloor + \frac{\text{Legal Balls} \pmod 6}{6}$$
- **Scoring Convention**: Wide balls and no-balls are illegal deliveries and do not increment `Legal Balls`.

### 2.3 Bowling Economy Rate
- **Definition**: Average runs conceded by the bowler per legal over.
- **Formula**:
  $$\text{Economy Rate} = \frac{\text{Bowler Conceded Runs}}{\text{Legal Overs Bowled}}$$
- **Conceded Runs Breakdown**:
  - Includes: `batter_runs` + `wide runs` + `no-ball runs`.
  - Excludes: `byes`, `leg-byes`, and `penalty runs` (charged to team extras, not bowler).

## 3. Form, Consistency & Temporal Analysis

### 3.1 Recent Form (Last $N$ Innings vs Last $N$ Matches vs Calendar Dates)
- **Strict Distinction**:
  - **`last_n_innings`**: The most recent $N$ innings in which the batter actually batted, ordered chronologically by match date and innings sequence.
  - **`last_n_matches`**: The most recent $N$ matches the player's team played.
  - **`start_date` / `end_date`**: Calendar boundaries independent of match appearances.

### 3.2 Performance Consistency ($\sigma$)
- **Definition**: Variance and standard deviation of runs scored across chronological innings.
- **Formula**:
  $$\mu = \frac{1}{N} \sum_{i=1}^N \text{runs}_i$$
  $$\sigma = \sqrt{\frac{1}{N} \sum_{i=1}^N (\text{runs}_i - \mu)^2}$$
- **Interpretation**: A lower $\sigma$ relative to $\mu$ denotes stable, predictable run scoring; a high $\sigma$ highlights innings volatility.
